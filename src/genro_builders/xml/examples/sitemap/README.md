# Sitemap example

A small, widely-known XSD bundled as a second codegen example next to
FatturaPA. The XML Sitemap format is the de-facto standard for telling
search engines which URLs a site exposes.

## Why this schema

It is tiny and readable yet exercises the codegen end to end:

- nested structure (`urlset` → `url` → `loc`/`lastmod`/`changefreq`/`priority`);
- cardinalities (`url[1:]`, `loc[1]`, the rest `[0:1]`);
- an enumeration (`changefreq` → `Literal['always', 'hourly', ...]`);
- a bounded numeric type (`priority` → `Annotated[Decimal, Range(0..1)]`).

## Files

- `sitemap.xsd` — the schema, **hand-authored from the public Sitemaps
  protocol 0.9 specification** (https://www.sitemaps.org/protocol.html).
  It is *not* the verbatim `sitemaps.org` schema file: it reproduces the
  documented structure (element names, cardinalities, the `changefreq`
  enumeration, the `priority` range) so it can be shipped here cleanly as
  an example. The Sitemaps protocol is a public, vendor-neutral standard.
- `sitemap.py` — generated by the codegen
  (`--dialect-name Sitemap`); declares `SitemapBuilder`.

## Usage

```python
from decimal import Decimal

from genro_builders.xml.examples.sitemap.sitemap import SitemapBuilder


class MySitemap(SitemapBuilder):
    def main(self, root):
        s = root.urlset()
        home = s.url()
        home.loc("https://www.example.com/")
        home.changefreq("daily")
        home.priority(Decimal("1.0"))


sm = MySitemap()
sm.create()
print(sm.render(mode="xml", pretty=True, target=False))
```
